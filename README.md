# Blog Backend
Spring Boot 4.0 + MyBatis-Plus + Spring Security + JWT

## 技术栈
- Java 21 / Spring Boot 4.0.6
- MyBatis-Plus 3.5.7
- Spring Security + JWT
- MySQL 8
- Redis（待接入）
- Agnes AI / SiliconFlow embedding

## 运行
```bash
cd backend
# 复制 application.yml 中的模板填写本地配置
# 或直接 IDEA 运行 BlogApplication.java
```
